# 📝 待办事项应用 (Todo App)

一个功能完整的待办事项管理应用，支持本地存储、分类/标签管理、任务过滤和数据导出。

## ✨ 功能特点

### 核心功能
- ✅ **添加待办事项** - 快速输入和管理任务
- ✅ **本地存储** - 所有数据自动保存到浏览器本地存储，无需后端
- ✅ **完成状态切换** - 标记任务完成或未完成
- ✅ **编辑任务** - 修改已存在的待办事项文本
- ✅ **删除任务** - 删除不需要的待办事项

### 分类/标签功能
- 🏷️ **创建分类** - 为任务分配标签/分类
- 🏷️ **自动关联** - 新创建的待办事项自动带有当前所有分类
- 🏷️ **按分类过滤** - 快速查看特定分类下的所有任务
- 🏷️ **删除分类** - 移除不需要的分类标签

### 过滤和统计
- 🔍 **状态过滤** - 查看全部、进行中或已完成的任务
- 🔍 **分类过滤** - 按标签过滤任务
- 📊 **统计信息** - 实时显示总数、进行中和已完成任务数量

### 数据管理
- 💾 **导出数据** - 将所有任务和分类导出为JSON格式备份
- 🗑️ **清除已完成** - 一键删除所有已完成的任务
- 🗑️ **清空全部** - 重置应用（需要确认）

## 🚀 快速开始

### 方式1：直接使用

1. 克隆或下载本项目
2. 在浏览器中打开 `index.html` 文件
3. 开始使用应用

### 方式2：本地服务器

```bash
# 使用Python
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

然后访问 `http://localhost:8000`

## 📖 使用指南

### 添加待办事项
1. 在输入框中输入任务文本
2. 点击"添加"按钮或按Enter键
3. 任务将立即添加到列表

### 管理分类/标签
1. 在分类输入框中输入标签名称
2. 按Enter键添加分类
3. 新创建的待办事项将自动包含所有当前分类
4. 点击分类标签上的"×"可删除分类

### 过滤任务
- **全部** - 显示所有任务
- **进行中** - 只显示未完成的任务
- **已完成** - 只显示完成的任务
- **按分类** - 点击分类按钮按标签过滤

### 编辑和删除
- 点击"编辑"按钮修改任务内容
- 点击"删除"按钮删除任务（需要确认）
- 点击复选框标记任务完成或未完成

## 💾 数据存储

所有数据存储在浏览器的 **localStorage** 中：
- 自动保存所有更改
- 刷新页面后数据不会丢失
- 清浏览器缓存会删除数据
- 支持导出数据作为备份

### 存储位置
- **键**: `todoAppData`
- **格式**: JSON
- **容量**: 通常5-10MB（取决于浏览器）

## 🐛 故障排除

### 问题：数据丢失
- **原因**: 清浏览器缓存或使用无痕模式
- **解决**: 导出数据作为定期备份

### 问题：无法保存数据
- **原因**: localStorage被禁用或已满
- **解决**: 检查浏览器隐私设置，清理存储空间

### 问题：样式显示异常
- **原因**: CSS文件加载失败
- **解决**: 确保CSS文件与HTML在同一目录
